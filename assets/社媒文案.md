## 四、知乎（1:1 · 回答 / 文章引流）

### 适合回答的问题

- 「有哪些小众但好用的开源项目？」
- 「程序员有哪些提高效率的神器？」
- 「如何评价 DeepSeek Harness？」

### 回答正文

```
分享一个我自己做的东西：把一整套本地 AI 工作栈装进一张 SD 卡。

背景是这样的：我平时的工作流跑在一台 Windows 上，DeepSeek Harness 本体、
一堆 MCP 服务、手机操控脚本、抖音自动化脚本，全靠一堆软链接串起来。
问题是一换电脑就废——路径全是写死的，装环境要装半天。

于是做了这么一套「随身卡」：插到任何一台 Windows 上，双击 bat 就跑。

技术上有三个点值得说：

1）路径不写死，每次启动现算
   卡插到别的机器上盘符可能变，所以启动脚本用 %~dp0 定位自己，
   再用一个 repath 脚本把配置里的绝对路径幂等地重写回去。
   幂等很重要——重跑十次结果得一样，不然配置会越改越乱。

2）exFAT 不支持软链接，这是硬约束
   SD 卡基本只有 exFAT 可选，而 exFAT 压根没有 junction/symlink。
   原本靠链接共享的 node_modules 全部实体化，校验脚本里专门断言「全树零链接」。

3）声明式裁剪，而不是手改配置
   卡上不想带某些模块（比如几十 GB 的语音模型），
   就写一个 portable-strip.txt，启动时按清单把配置块整段移除。
   比手动注释掉靠谱，而且换机器同步配置时不会被带回来。

还有一个教训来自国产 ROM：荣耀 MagicOS 会冻结后台进程——
不只是后台，连 is_front:1 的前台进程都会被 freeze。
我试过 deviceidle 白名单、appops RUN_ANY_IN_BACKGROUND、
app_hibernation，全部无效。唯一有效的是用户在系统设置里手动加白名单。
这件事没有 API 可以绕过，只能写进文档让用户自己点。

代码 MIT 开源：github.com/80355/dsh-portable-kit
文档一万两千多字，39 条问答，踩过的坑基本都记了。
```

## 五、公众号（首图 banner 900×383 + 图文）

### 标题

**一张 SD 卡，装下一整套 AI 工作栈**

### 摘要（发布时填，上限 120 字）

> 插到任何 Windows 上双击就能跑：便携运行时、手机操控、抖音自动化、本地控制台、新手启动器。踩过的坑——exFAT 不支持软链接、MagicOS 冻结前台进程、内联回复为什么做不成——全写进文档了。MIT 开源。

### 正文

```
（首图：assets/social/wechat-banner.png）

## 为什么做这个

我日常的工作流跑在一台 Windows 上：DeepSeek Harness 本体、
五六个 MCP 服务、手机操控脚本、抖音自动化脚本，互相之间靠软链接串起来。

它在我这台机器上跑得很好，但一换电脑就废。
路径写死、环境要重装、配置要重配——一个下午就没了。

所以我想：能不能把它做成一张卡？插上就跑，拔了就走，记忆还跟着走。

## 卡里有什么

插上卡，双击 `start-gui.bat`，浏览器会打开一个本地页面：

1. **体检** —— 八项一次看完：Node 有没有、DSH 在不在、目录能不能写、
   端口有没有被占、Key 填了没有。缺什么一目了然。
2. **配置** —— 四类 API Key 都在这里填，九个模块可以单独开关。
3. **运行** —— 一键启动，日志实时滚动。
4. **帮助** —— 常见问题内置在里面，不用去翻文档。

除了启动器，卡里还有：

- **便携运行时**：盘符变了自己找对路，8 组自检，退出码就是结论。
- **手机操控**：截图 → 视觉模型看画面 → 拿到界面节点树 → 真点击。
  坐标只从节点树里取，不从画面上猜。
- **抖音自动化**：接管你自己已登录的浏览器，不开无头、不模拟登录。
- **本地控制台**：一个面板管理全部后台服务，带模块开关和 Key 管理。

## 三个真实的坑

**坑一：exFAT 不支持软链接。**
SD 卡基本只有 exFAT 可选，而它压根没有 junction/symlink。
原本靠链接共享的依赖全部实体化，校验脚本里专门断言「全树零链接」，
防止哪天又被悄悄建回去。

**坑二：路径必须现算，而且重写要幂等。**
盘符会变，所以启动脚本用 `%~dp0` 定位自己，
再用 repath 脚本把配置里的绝对路径重写回去。
幂等是硬要求——重跑十次结果得一样，否则配置会越改越乱。

**坑三：国产 ROM 的冻结，没有 API 能绕。**
荣耀 MagicOS 会周期性冻结进程，连 `is_front:1` 的前台进程都不放过。
我试过设备白名单、后台运行授权、休眠豁免，全部无效。
唯一有效的是用户去系统设置里手动加白名单——这件事只能写进文档，
让用户自己点，绕不过去。

## 还有一个「做不到」

微信的第三方通知，想加一个像 X / Ins 那样的「内联回复」按钮。
技术上做不成：微信从来没有把带 RemoteInput 的 PendingIntent 交给第三方，
`Notification.CarExtender` 在 Android 13 之后也已废弃。
X / Ins 能内联回复，是因为那是它们自己的通知。

所以最后的方案是：点通知直接跳到对应的聊天窗口。
不花哨，但每次都管用。
```
