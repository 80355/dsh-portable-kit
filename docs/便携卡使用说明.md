# DSH 便携版（SD 卡即插即用）

这张卡里装着一整套 DeepSeek Harness：程序、配置、插件、记忆、人格都在卡上（语音模型按作者要求没带，见第四节末）。
**换一台 Windows 电脑，插上卡，双击 `start-dsh.bat` 就能用**，不需要在那台电脑上装任何东西。

---

## 一、卡上结构

```
<卡>\DSH\
  start-dsh.bat        ← 主启动器（双击这个）
  start-all.bat        ← 先起本地控制台(3300)，再起 DSH
  portable-repath.mjs  ← 每次启动自动把配置里的写死路径改成当前盘符（幂等，毫秒级）
  portable-verify.mjs  ← 自检：插到新电脑前/后跑一次，确认能不能用
  sync-to-card.ps1     ← 在老机器上跑：把最新的记忆/人格/会话同步进卡里
  node\                ← 便携 Node 运行时（v22.22.2，含 npm / pnpm / corepack）
  dsh-workspace\       ← DSH 本体（@deepseek-ai/dsh + 依赖）
  .dsh\                ← DSH_HOME：profiles、会话、凭据、插件、抖音浏览器数据、人格卡
  workspace\           ← 工作区（原来 D 盘的 default-workspace：qq-bridge、console、
                          抖音、共享记忆……；语音模型未带）
```

盘符**随便变**：启动脚本全部用 `%~dp0` 自解析。在你这台机器是 `E:`，插到别的机器变成 `F:`、`G:` 也照样跑。

---

## 二、怎么用

### 1. 直接开 DSH（最常用）
双击 `start-dsh.bat` → 浏览器打开 `http://127.0.0.1:3080` → 就是你现在看到的这个界面。
关掉黑窗口 = 关掉 DSH。

### 2. 连本地控制台一起开
双击 `start-all.bat`（控制台面板在 `http://127.0.0.1:3300`）。

### 3. QQ 桥接 / SnowLuma / 语音这些「附加服务」按需单独开
进 `workspace\` 里双击对应脚本（它们已经是相对路径写法）：

| 想开什么 | 双击 |
|---|---|
| QQ 桥接（MCP 私聊/群聊） | `workspace\启动桥接.bat` |
| SnowLuma 网关 | `workspace\启动SnowLuma.bat` |
| 本地控制台 | `workspace\启动控制台.bat` |
| 抖音自动分享 | `workspace\启动抖音自动分享.bat` |
| 全都要 | `workspace\启动全部.bat` |

> **卡上不带语音**（作者 2026-11-07 起）：GPT-SoVITS + RVC 一共 34.4 GB 已从卡里删掉，
> 配置里的 `tts-voice` MCP 条目也一并摘掉了（记录在卡根的 `portable-strip.txt`）。
> DSH 本体、QQ 桥接、抖音、记忆、人格都**不受影响**，只是没有本地克隆音色而已。
> 想把语音加回来：把 `gpt-sovits\`、`rvc\` 拷回 `workspace\`，再删掉 `portable-strip.txt` 里那一行。

## 三、第一次插到一台新电脑，要注意

1. **必须是 64 位 Windows 10/11**。卡里带的是 win32-x64 的 Node 和原生模块。
2. **可能会弹 Windows 防火墙**（Node 要监听 3080）：点「允许访问」。
3. **杀毒软件**可能对 `node\` 里的 exe 报「未知文件」，放行即可。
4. **exFAT 卡没有 NTFS 权限控制**：别在公共电脑上开（`.dsh\.credentials.yaml` 里是 API Key 明文）。
5. 卡是 USB/读卡器速率，**首次启动会比硬盘慢 10~60 秒**（要读几万个插件文件），属正常。
6. 如果那台电脑已经装过 DSH、`%USERPROFILE%\.dsh` 已存在：**本便携版不碰它**（本栈用环境变量 `DSH_HOME` 指到卡上），互不干扰。

## 四、换机器前：把最新的记忆同步进卡

卡上的记忆/人格是你**复制那一刻**的快照。走之前想在"大肥鱼"身上带上最新记忆，就在**原来的机器**上跑：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File <卡>\DSH\sync-to-card.ps1 -CardRoot E:\DSH
```

它只搬该搬的（不碰 475MB 浏览器缓存和 node_modules）：

| 同步什么 | 从哪 → 到哪 |
|---|---|
| 共享记忆 `大肥鱼记忆.md` | `workspace\shared\` → 卡 |
| 抖音记忆库 + 人格卡 | `%USERPROFILE%\.dsh\douyin-browser\memory\` → 卡 |
| 私信发送回执 / 观看状态 | `douyin-browser\dm-share-receipts.json`、`state\` → 卡 |
| 会话记录 | `.dsh\sessions\`、`.dsh\storages\` → 卡 |
| 凭据 / 配置 | `.dsh\.credentials.yaml`、`profiles\web\{cordis.patch.yml,package.json}` → 卡 |
| QQ 人格 | `qq-bridge\roles\` → 卡 |

**只往卡里写，永远不删老机器上的东西。**

## 五、自检（强烈建议）

在卡根目录（`<卡>\DSH\`）开个终端跑：

```bat
node\portable-verify.mjs
```

或者双击不行时手动：

```bat
node\portable-verify.mjs
```

检查内容：Node 能否执行、DSH 本体在不在、配置里有没有残留**别的机器**的写死绝对路径、
QQ 插件（原来是 junction，exFAT 上已换成实体目录）是否完整、记忆/人格卡在不在、
有没有 exFAT 不支持的符号链接。

结果三种：`全部通过` / `关键项通过+警告` / `有 FAIL 项`。

## 六、故障排查

| 现象 | 原因 / 处理 |
|---|---|
| 黑窗口一闪就没 | 右键 `start-dsh.bat` → 「编辑」看在哪一步 `[X]` 报错；常见是 `node\` 或 `dsh-workspace\` 没复制全 |
| 3080 打不开但窗口开着 | 看窗口里有没有 `dsh: warning` 之后卡住；多半是端口被占（换 `start-dsh.bat --port 3081`，参数会透传） |
| 插件全没了 / 图标变默认 | `.dsh\profiles\web\node_modules` 复制不全 → 重新整包复制 `.dsh` |
| 记忆/人格是旧的 | 卡上的是**复制那一刻**的快照；想同步回最新，从机器上再复制一次 `%USERPROFILE%\.dsh\douyin-browser` 和 `workspace\shared` |
| 换了盘符后 MCP 全红 | 正常不会发生（启动器每次重写），可手动跑 `node\portable-repath.mjs` 看输出 |
| QQ 桥接起不来 | 它需要 SnowLuma 在 5099；先开 `启动SnowLuma.bat`。桥接日志在 `workspace\qq-bridge\logs` |

## 七、已知限制（别踩坑）

1. **exFAT 不支持 junction / 符号链接**。所以原来 `.dsh` 里那 3 个 junction
   （`qq-agent-presets`、`qq-mode-console`、`@deepseek-ai/schemastery`）在卡上**已经换成实体目录副本**。
   以后在卡上跑 `pnpm install` 会把它们变回链接 → **不要在卡上重装依赖**。
2. **不要在卡上跑 `pnpm install` / `npm install`**（同上）。
3. `build-tools`（Android SDK / adb / 编译工具链，2.4 GB）**没带上卡**，只保留了 `platform-tools\adb.exe`。
   要在别的电脑上编译 APK，得自己再装 Android SDK。
4. **语音模型没带上卡**（按作者设置，省 34.4 GB）。卡上 `.dsh` 里的 `mcp-tts-voice`
   已由 `portable-strip.txt` 关掉；想加回来：把 `gpt-sovits\`、`rvc\` 拷回 `workspace\`，
   删掉 `portable-strip.txt` 里那一行，下次启动自动恢复配置。另：`rvc\venv` 是绑死本机
   Python 的虚拟环境，换电脑即便拷过去也要重建 venv。
5. 这份 README 与脚本本身也在卡上：`<卡>\DSH\README-便携使用.md`。
6. 卡是**数据盘**，别在 DSH 运行时拔卡（和拔移动硬盘一个道理）。

## 八、想再复制一份 / 换个盘

整个 `<卡>\DSH` 目录就是全部，拷到另一个盘/另一张卡，双击 `start-dsh.bat` 即可。
不需要改任何文件——路径都是启动时算的。
