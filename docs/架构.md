# 架构

一句话：**这不是一个 agent，是围绕 agent 的一层「随身 + 有手」的壳。**

---

## 分层

```text
┌──────────────────────────────────────────────────────────┐
│  你的入口                                                  │
│  ├─ 网页控制台  http://127.0.0.1:3300   (console/)          │
│  ├─ DSH Web UI http://127.0.0.1:3080   (dsh 本体)           │
│  └─ QQ / 私信 / 定时脚本                                     │
├──────────────────────────────────────────────────────────┤
│  DSH agent 运行时（外部依赖，不在本仓库）                       │
│  └─ MCP 工具 ← cordis.patch.yml 注册                          │
├──────────────────────────────────────────────────────────┤
│  本仓库提供的手脚与后勤                                       │
│  ├─ tools/phone/   ADB + 视觉 + 节点树  →  操作一台真手机        │
│  ├─ scripts/douyin/ CDP                →  操作一个真浏览器      │
│  └─ console/       本地 HTTP 面板       →  拉起/重启各个服务     │
├──────────────────────────────────────────────────────────┤
│  便携层（portable/）                                          │
│  ├─ start-dsh.bat        所有路径从 %~dp0 现算                  │
│  ├─ portable-repath.mjs  幂等重写 MCP/依赖路径 + 清单裁剪        │
│  ├─ portable-verify.mjs  8 组自检，退出码即结论                  │
│  └─ sync-to-card.ps1     老机器 → 卡 的单向同步                  │
└──────────────────────────────────────────────────────────┘
```

## 卡上的布局

```text
<卡>\
├─ start-dsh.bat          ← 双击这个
├─ start-all.bat          ← 连控制台一起起
├─ portable-repath.mjs
├─ portable-verify.mjs
├─ portable-strip.txt     ← 声明式裁剪清单
├─ sync-to-card.ps1
├─ node\                  ← 便携 node（含 npm/pnpm/corepack）
├─ dsh-workspace\         ← DSH 本体 + 它的 node_modules
├─ .dsh\                  ← 配置、会话、记忆、凭据
│  ├─ .credentials.yaml   ← ⚠ 明文，别插公共电脑
│  └─ profiles\web\       ← cordis.patch.yml / package.json
└─ workspace\             ← 你自己的工具与数据
   ├─ shared\             ← 共享记忆（跨入口同一份）
   ├─ qq-bridge\          ← 独立项目，这里只放一份
   ├─ console\
   ├─ tools\phone\
   └─ scripts\douyin\
```

## 启动时序

`start-dsh.bat` 做的事，顺序严格：

```text
1. ROOT = %~dp0                       ← 盘符变了也无所谓
2. 设 DSH_HOME / DSH_WORKSPACE
3. PATH = <卡>\node;%PATH%            ← 插件可能 spawn 裸 node
4. NODE_PATH = <卡>\workspace\...      ← 让 require 找得到桥接的依赖
5. node portable-repath.mjs           ← 重写配置路径 + 应用 strip 清单
6. cd <卡>\workspace
7. node <卡>\dsh-workspace ...\bin.js web
```

**第 5 步在 7 步之前**是关键：MCP 服务的路径必须在 DSH 读取配置前就已正确，
否则 DSH 会拿着上一次（别的盘符）的绝对路径去 spawn，直接 ENOENT。

---

## 为什么用「每次启动都重写」而不是「相对路径」

- 有些配置项（MCP 的 `command`）必须是**绝对路径**，写相对路径 DSH 不认；
- 而绝对路径一旦换盘就废；
- 所以只能「存一份可被重写的、启动时校准」。这是唯一同时满足两个约束的做法。

幂等的实现要点：重写只在**值真的不同**时才写盘，且用固定格式生成，
所以跑第二遍是 no-op，git diff 也是干净的。

## 依赖方向（有意保持单向）

```text
portable/   ← 谁都不依赖，只依赖 node 与文件系统
console/    ← 依赖 portable 产出的路径约定
tools/      ← 完全独立（只依赖 adb / 视觉 API）
scripts/    ← 完全独立（只依赖浏览器 9222）
```

好处：任何一块单独拿走都能用。比如你只想要「手机操控」，
那就把 `tools/phone/` 拷出去，不需要整个栈。

## 设计取舍

| 选择 | 放弃了什么 | 为什么值得 |
| --- | --- | --- |
| 截图+节点树双通道 | 简单性 | 单一通道在重绘型 App 上错得离谱 |
| 接管真实浏览器 | 可无人值守 | 真实会话比无头稳定得多，风控风险也低 |
| 每次启动重写路径 | 「一次配好不动」 | 便携性的前提就是配置可变 |
| 声明式 strip 清单 | 灵活性 | 让「带什么/不带什么」变成一行字，而不是一次改代码 |
| exFAT 上实体化链接 | 磁盘占用 | exFAT 不支持链接，实体化是唯一可行解 |
