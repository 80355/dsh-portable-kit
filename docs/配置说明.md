# 配置说明

这个仓库里**没有任何写死的个人配置**。所有需要你自己填的东西，都在这里。

---

## 一、环境变量（全部可选，有默认值）

| 变量 | 作用 | 默认 | 用在哪 |
| --- | --- | --- | --- |
| `ADB_BIN` | adb 可执行文件路径 | `adb`（取 PATH） | `tools/phone/phone-vision.mjs`、`tools/phone/adb.sh` |
| `PHONE_SERIAL` | 目标设备序列号（多设备时必填） | 空 = 自动选无线设备 | 同上 |
| `COCO_KEY` | 视觉模型 API Key | 无（**必填**才能用手机操控） | `tools/phone/phone-vision.mjs` |
| `OPENAI_API_KEY` | 同上，`COCO_KEY` 的备用名 | — | 同上 |
| `FFMPEG` | ffmpeg 可执行文件 | `ffmpeg`（取 PATH） | 视频抽帧/截图拼接 |
| `DSH_HOME` | DSH 配置根目录（放 `.dsh` 的地方） | `%USERPROFILE%\.dsh` | `portable/*`、`scripts/douyin/auto-share-watch.mjs` |
| `DSH_WORKSPACE` | 工作区根目录 | 脚本同级 `workspace` | `start-dsh.bat` |
| `DSH_CHECKOUT` | DSH 源码 checkout 目录 | `<workspace>/../dsh-workspace` | `console/server.mjs` |
| `DSH_QQ_CONSOLE_NODE` | 控制台用哪个 node 启动子进程 | `process.execPath` | `console/server.mjs` |
| `DSH_QQ_CONSOLE_VERBOSE` | 控制台详细日志 | 关 | `console/server.mjs` |
| `QQ_EXE` | QQ 客户端路径（控制台一键拉起用） | 空 | `console/server.mjs` |
| `PV_TRACE` | 手机操控的调试追踪 | 关 | `tools/phone/phone-vision.mjs` |

### 视觉模型端点

`phone-vision.mjs` 顶部两个常量可直接改，用于换厂商：

```js
export const COCO_BASE = 'https://api.cocoapi.top/v1/chat/completions';
export const VISION_MODEL = 'claude-sonnet-5';
```

任何 OpenAI 兼容的 `chat/completions` 且支持图像输入的模型都能用
（GPT-4o 系、Claude 系、Gemini 系、Qwen-VL 等）。

## 二、声明式清单：`portable-strip.txt`

放在栈根目录（卡根）。一行一个要**整块移除**的配置 id 前缀，`#` 开头是注释。

```text
# 语音模型太大，这套栈不带
mcp-tts-voice
```

`portable-repath.mjs` 每次启动都会读它，把 `cordis.patch.yml` 里对应的缩进块整段摘掉，
并留下一行注释：

```yaml
# [portable] 已按 portable-strip.txt 移除: mcp-tts-voice-7
```

**幂等**：跑多少遍都只有这一行注释，不会重复删、不会报错。
想恢复：删掉清单里那一行，重启即可。

## 三、控制台面板：`console/panel.config.json`

控制台的**运行时**配置（不在仓库里，已 `.gitignore`），首次启动会生成。
可覆盖项见 [`examples/panel.config.example.json`](../examples/panel.config.example.json)：

| 键 | 说明 |
| --- | --- |
| `qqExe` | QQ 客户端路径 |
| `bridgePort` / `consolePort` | 端口（默认 3100 / 3300） |
| `dshUrl` | DSH 本体地址（默认 `http://127.0.0.1:3080`） |
| `snowlumaPort` | SnowLuma 网关端口（默认 5099） |
| `settings.modules` | 模块开关状态（由面板「⚙️ 模块开关 & API 配置」写入） |
| `settings.env` | 面板里填的 API Key（写入进程环境变量；空值会被删除） |

### 面板里的「模块开关 & API 配置」

打开 `http://127.0.0.1:3300` 就能看到这一块，不用手改任何文件：

- **本地服务开关**：QQ 模块（3100）、SnowLuma 网关（5099）、抖音自动化、手机遥控 —— 控制控制台会不会去拉那几个进程。
- **MCP 工具开关**：对应 `cordis.patch.yml` 里的五个条目。勾掉 → 往 `portable-strip.txt` 追加一行 id 前缀 →
  立刻跑一次 `repath` 把该缩进块摘掉。**这是真删除，不是界面隐藏**：重启 DSH 后那些工具不再出现在工具列表里。
- **API Key**：四类（视觉/多模态、OpenAI 兼容、模型通道、备用线路）。保存后写进
  `console/panel.config.json` 的 `settings.env`，之后控制台拉起的 SnowLuma、QQ 桥接、DSH 子进程都会带上。
  已经存过的 Key 回读时只返回打码形式（`sk-d…3456`），明文不会回到浏览器。

> 面板只监听 `127.0.0.1`，CORS 也只放行 `http://127.0.0.1:3300`；
> 但它**不做鉴权**——别把 3300 映射到局域网或公网。

## 四、`.dsh` 配置里的 MCP 条目

便携栈的核心技巧：`cordis.patch.yml` 里的 `command` / `args` 写的是**当前栈的绝对路径**，
但每次启动都会被 `portable-repath.mjs` 重写一遍，所以你**不要手改**。

模板见 [`examples/cordis.patch.example.yml`](../examples/cordis.patch.example.yml)。

| --- | --- | --- |
| `.dsh/.credentials.yaml` | 模型 provider 的 Key | ❌ 已忽略 |

# 浏览器开 9222 即可，无需环境变量
