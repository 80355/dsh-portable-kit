最常见的问题

下面这几条能覆盖九成「第一次用跑不起来」。更细的看 docs/功能手册与问答.md。

双击后窗口一闪就没了

说明 Node 没找到。开一个终端（Win+R 输入 cmd），把 start-gui.bat 拖进去回车，就能看到真实报错。常见两种：卡上没有 node\ 目录；或者卡符变了但脚本里写死了旧盘符（用新版脚本即可，路径都是现算的）。

提示端口被占用（3080 / 3300 / 3400）

先点「全部停止」，还不行就在终端里跑 netstat -ano | findstr :3080 找到 PID，再到任务管理器结束那个 node.exe。换端口也行：node launcher/server.mjs --port 3401。

浏览器打开是 401 /「authentication required」

正常现象，说明服务活起来了但需要带 token。地址里必须带 ?token=... 那一串 —— 点界面上的「在浏览器打开 DSH」，它会把完整地址给你。不要手动输 http://127.0.0.1:3080 就去访问。

DSH 启动了但 agent 不回答 / 一直报模型错误

九成是 Key 没填或填错。回到第 2 步，填「模型通道 Key」，点旁边的「测试」看是否 HTTP 200；再不行看日志里具体报错（401 = key 错，402/429 = 额度或限流）。

换了台电脑插上卡，什么都不对

盘符变了。先跑一次 node portable-repath.mjs（在卡根），它会把配置里的绝对路径改成当前盘符；然后重新双击启动器。别手动改配置文件里的盘符，容易漏。

手机连不上（adb devices 是空的）

先确认手机开了「开发者选项 → USB 调试」，插上后在手机上点「允许」。无线的话要先配对：adb pair 192.168.x.x:端口 配对码。连上后 adb devices 应该能看到序列号 —— 注意它和显示名之间是 Tab 不是空格，脚本里别用空格切分。

能不能把它给别人用 / 放到公网？

能给别人，但别放公网。启动器和控制台都只监听 127.0.0.1 且没有登录鉴权，一旦映射出去等于把整台机器的文件和命令执行权交出去。
